# モン・サン・ミシェルさんぽ

サン・マロ湾に浮かぶ修道院の島を、スマホで歩いて巡る3D散策。
世界さんぽシリーズ（ヴェルサイユ宮殿さんぽ）と同じ操作系（three.js r128・単一HTML）。

- 島：2014年の橋（パスレル）、前衛門とミシュレット砲、ブールヴァール門、王の門（落とし格子・跳ね橋）、グランド・リュ（店と吊り看板）、サン・ピエール教会、城壁の回廊と6つの塔、外の大階段、シャトレ
- 修道院：衛兵の間、大階段（グラン・デグレ）、太柱の礼拝堂（地下聖堂）、西のテラス、ソー・ゴーティエ、付属教会（ロマネスクの身廊・フランボワイヤンの内陣・飛び梁）、尖塔と金の大天使
- ラ・メルヴェイユ：回廊（互い違いの二列の柱）、食堂、迎賓の間、騎士の間、大車輪（監獄の時代）
- 湾：潮の満ち引き（満潮／干潮、約16秒で満ちる）、干潟を歩いて島を一周、聖オベール礼拝堂、ガブリエル塔、北から見たラ・メルヴェイユ、対岸の牧草地の羊
- とき：中世の巡礼（1530年ごろ・橋なし・身廊が西へ長い）／監獄の時代（1840年ごろ・腕木通信・大車輪が回る）／現在
- 時刻：朝・昼・夕・夜（修道院のライトアップ・星）
- 見どころ札集め（全30・歩いて訪れたときだけ。干潟の札は干潮のときだけ）、大天使の印（西のテラスに着いたとき）、写真モード、道案内、合成音（海風・波・カモメ・鐘・聖歌風の響き）

建物や地形は簡略な再現で、部屋の大きさ、通りや城壁の長さ、橋の長さなどは歩きやすいように整えています。
